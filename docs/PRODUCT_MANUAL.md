# A股量价信号工作台产品说明书

版本：0.1.0  
适用对象：股票研究、盘后复盘、候选股筛选、交易计划制定用户  
产品定位：本产品用于把 A 股日线行情数据转换为结构阶段、关键价位、量价信号、候选评分、雷达诊断、价格预测和回测结果，帮助用户形成更一致、更可复盘的交易观察流程。

> 重要提示：本产品仅用于研究、复盘和辅助决策，不构成任何投资建议、收益承诺或自动交易指令。用户应结合自身风险承受能力、真实交易规则、资金管理、滑点、手续费、市场环境和合规要求独立判断。

## 1. 产品概览

### 1.1 产品解决的问题

A 股短线和波段交易中，很多判断依赖主观经验，例如“放量突破是否有效”“回踩是不是买点”“高位放量是不是出货”“这只股票是不是强于大盘和板块”。本产品把这些经验拆解为可计算的模块：

- 识别当前股票所处的市场结构阶段。
- 提取支撑位、压力位、放量 K 线、地量 K 线等关键价位。
- 根据量价关系识别买入、观察、卖出和回避信号。
- 用统一评分体系衡量候选质量。
- 用强股雷达判断股票质量、买点质量和卖出风险。
- 用统计预测模型估计未来 10 个交易日价格路径。
- 用回测模块验证信号在历史数据中的表现。

### 1.2 产品核心原则

本产品遵循“量价优先、结构过滤、风险前置、预测辅助”的原则。

量价优先：最终操作建议优先服从价格和成交量出现的真实信号。  
结构过滤：主跌结构、高位派发结构会显著降低买入优先级。  
风险前置：止损距离、失效价、卖出风险会参与最终决策。  
预测辅助：预测模型不直接替代量价信号，只作为对买点和风险的统计确认。

## 2. 数据说明

### 2.1 输入数据

系统使用日线 OHLCV 数据。最低要求字段如下：

| 字段 | 含义 |
| --- | --- |
| date | 交易日期 |
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| volume | 成交量 |

推荐额外字段：

| 字段 | 含义 |
| --- | --- |
| amount | 成交额，用于流动性过滤 |
| symbol | 股票代码 |

### 2.2 数据来源

系统支持在线 A 股数据和本地 CSV 数据。

在线数据通过 AKShare 获取，常用于普通用户快速分析。  
本地 CSV 适合用户使用自己的清洗数据、复权数据或内部行情源。

### 2.3 数据长度要求

稳定量价诊断至少需要 60 个交易日。  
价格预测至少需要 250 个有效交易日。  
更完整的模型训练默认使用最近 750 个交易日作为回看窗口。

## 3. 功能模块说明

### 3.1 单票诊断

单票诊断用于分析某一只股票当前状态。输出内容包括：

- 当前收盘价。
- 市场结构阶段。
- 量价综合分。
- 最终统一建议。
- 支撑位和压力位。
- 量价信号及证据。
- 止损价、买入区间和失效条件。
- 强股雷达诊断。
- 如启用预测，则输出未来价格路径和上涨概率。

### 3.2 股票池扫描

股票池扫描用于批量筛选候选股。系统会对每只股票运行同一套诊断流程，并根据候选分、最终动作和最低分过滤结果。

常见用途：

- 扫描指数成分股。
- 扫描行业板块。
- 扫描概念板块。
- 扫描本地 CSV 股票池。
- 生成可下载的候选股 CSV。

### 3.3 我的备选池

备选池用于保存单票诊断或扫描结果中的候选股票。适合盘后复盘时建立观察清单，后续继续跟踪评分、信号和关键价位变化。

### 3.4 已购买

已购买模块用于记录用户已经持有或计划跟踪的标的，方便区分“准备买入的候选”和“已经进入持仓管理的股票”。

### 3.5 策略回测

回测模块用于验证历史信号，不用于保证未来收益。系统支持单票回测和组合回测。

单票回测规则：

- 买入条件：出现买入信号，并且量价分不低于最低买入分。
- 成交价格：信号日后的下一个交易日开盘价，并计入滑点。
- 仓位计算：根据单笔风险比例和止损距离倒推出买入股数。
- 卖出条件：出现卖出信号、触发止损，或数据结束时平仓。
- 成本模型：买入计佣金，卖出计佣金和印花税。

组合回测主要用于“第二阶段主升 + 缩量回踩 + 上涨中继买点”策略。该入口不会把突破、底部反转、区间低吸混在一起，更适合验证趋势回踩策略的实际表现。

### 3.6 跟随交易

跟随交易用于开盘前根据美股、韩股前一晚或近期强势表现，映射到 A 股上游或相关产业链公司。

逻辑流程：

1. 选择海外强势股，或手工输入海外标的涨跌幅。
2. 系统根据内置产业链映射表查找相关 A 股公司。
3. 根据海外涨跌幅和映射强度生成跟随分。
4. 可叠加 A 股量价诊断，过滤结构较弱或买点较差的标的。
5. 输出开盘观察清单。

跟随交易仅生成观察清单，不自动下单。若 A 股高开超过 5%，原则上不追；开盘后跌破开盘价且放量，应放弃跟随。

## 4. 量价交易算法逻辑

### 4.1 整体分析流程

系统对每只股票按以下顺序处理：

1. 标准化日线数据。
2. 计算价格、成交量、均线、波动率等特征。
3. 判断市场结构阶段。
4. 识别支撑位和压力位。
5. 识别量价买卖信号。
6. 计算相对强度。
7. 生成量价综合评分。
8. 运行强股雷达。
9. 生成最终统一建议。
10. 如启用预测模型，则输出未来价格路径和统计结论。

### 4.2 特征计算逻辑

系统会从 OHLCV 数据中派生以下核心特征：

| 名词 | 含义 |
| --- | --- |
| pct_change | 收盘价相对前一日收盘价的涨跌幅 |
| amplitude | 当日振幅，即最高价减最低价后除以前一日收盘价 |
| body_ratio | K 线实体占当日价格区间的比例 |
| upper_shadow_ratio | 上影线占当日价格区间的比例 |
| lower_shadow_ratio | 下影线占当日价格区间的比例 |
| close_position | 收盘价在当日高低区间中的位置，越接近 1 表示收盘越靠近最高价 |
| vol_ma5 | 5 日平均成交量 |
| vol_ma10 | 10 日平均成交量 |
| vol_ma20 | 20 日平均成交量 |
| vol_ma60 | 60 日平均成交量 |
| vol_ratio | 当日成交量除以 20 日平均成交量 |
| volume_trend_down | 成交量是否呈 5 日均量 < 10 日均量 < 20 日均量的萎缩趋势 |
| volume_trend_up | 成交量是否呈 5 日均量 > 10 日均量 > 20 日均量的放大趋势 |
| ma_fast | 20 日均线 |
| ma_slow | 60 日均线 |
| ma_long | 120 日均线 |
| ma_fast_slope | 20 日均线 5 日变化率 |
| ma_slow_slope | 60 日均线 10 日变化率 |
| rolling_high_60 | 最近 60 日最高价 |
| rolling_low_60 | 最近 60 日最低价 |
| range_pct_60 | 最近 60 日区间宽度 |
| gain_from_120_low | 当前收盘价相对 120 日低点的涨幅 |
| drawdown_from_120_high | 当前收盘价相对 120 日高点的回撤 |
| red_fat_green_thin | 近 20 日阳线数量和阳线实体强于阴线，表示需求占优 |
| green_fat_red_thin | 近 20 日阴线数量和阴线实体强于阳线，表示供给占优 |

### 4.3 市场结构阶段

系统把股票分为六种结构：

| 阶段 | 含义 | 典型特征 |
| --- | --- | --- |
| 第一阶段-筑底 | 长期回落后低位窄幅横盘 | 波动收敛、均线走平、成交量偏低 |
| 第二阶段-主升 | 需求占优的上升阶段 | 收盘价在 20 日、60 日均线上方，均线多头，近期高低点抬高 |
| 第三阶段-筑顶/高位震荡 | 大幅上涨后高位宽幅震荡 | 涨幅较大、成交活跃、波动放大、趋势不再顺畅 |
| 第四阶段-主跌 | 供给占优的下降阶段 | 收盘价在 20 日、60 日均线下方，均线空头，近期高低点下移 |
| 区间震荡 | 供需暂时平衡 | 60 日区间较窄，均线走平 |
| 结构不明 | 信号混杂 | 趋势、位置和量价条件不足以稳定归类 |

结构阶段是系统最重要的过滤器之一。主升阶段的缩量回踩优先级最高；主跌阶段即使出现短线反弹，也通常不会被当作买点。

### 4.4 关键价位识别

系统识别两类价位：支撑位和压力位。

支撑位来源：

- 最近 60 日区间低点。
- 最近 120 日内的局部前低。
- 放量 K 线低点。
- 地量 K 线低点。

压力位来源：

- 最近 60 日区间高点。
- 最近 120 日内的局部前高。
- 放量 K 线高点。
- 地量 K 线高点。

关键价位会被用于判断突破、跌破、回踩、止损、盈亏比和失效条件。

### 4.5 买入类信号

#### 4.5.1 向上突破买点

适用结构：筑底、区间震荡或结构不明，且不能处于主跌或派发阶段。

核心条件：

- 收盘价有效突破最近压力位。
- 前一日尚未有效突破。
- 当日成交量放大，或处于历史高量状态。
- K 线为强阳线，收盘靠近高位。
- 突破前存在缩量或波动收敛。

含义：需求开始打破原有供需平衡，价格从平台右侧向上突破。

#### 4.5.2 上涨中继买点

适用结构：第二阶段主升。

核心条件：

- 当前处于主升结构。
- 价格回踩到关键支撑附近。
- 回踩过程中成交量萎缩。
- K 线波动收敛或实体变小。
- 支撑未被有效跌破。
- 当日没有放量长阴等强供给信号。

含义：主升趋势中的正常回踩，供给不足，需求可能重新接管。

这是系统组合回测中重点验证的策略类型。

#### 4.5.3 区间底部低吸

适用结构：筑底或区间震荡。

核心条件：

- 收盘价接近区间底部。
- 出现跌破失败、放量滞跌或缩量止跌。
- 收盘重新回到支撑附近或支撑上方。

含义：供给尝试向下打破平衡但失败，区间底部可能存在需求吸收。

该信号通常属于观察或轻仓试探，不等同于主升确认。

#### 4.5.4 底部反转买点

适用场景：前期存在明显下跌或阶段新低。

核心条件：

- 前面存在下降趋势、恐慌放量或新低。
- 当日出现放量需求。
- 出现阳包阴、长下影、放量滞跌等反转形态。
- 收盘未继续创出有效新低。

含义：下跌末端可能出现需求吸收，但底部类信号不如主升回踩稳定，需要轻仓和二次确认。

#### 4.5.5 底部反转后缩量回踩

适用结构：筑底、区间震荡或结构不明。

核心条件：

- 前期已出现过放量阳线、长下影或放量滞跌。
- 随后回踩时成交量萎缩。
- 回踩未跌破底部低点。

含义：前期需求出现后，供给没有重新占优，底部结构可能改善。

### 4.6 卖出和回避类信号

#### 4.6.1 向下突破卖点

核心条件：

- 收盘跌破区间底部或关键支撑。
- 成交量放大或 K 线为强阴线。
- 当前结构属于区间、主升后期、派发或不明结构。

含义：供给打破原有平衡，价格可能进入新的下跌阶段。

#### 4.6.2 向下反转卖点

核心条件：

- 前面处于上升、区间顶部或高位结构。
- 出现阴包阳、冲高失败、长上影或放量长阴。
- 成交量放大确认供给。
- 跌破短期低点或收盘靠近低位。

含义：原本需求占优的结构被供给反包或压制。

#### 4.6.3 放量滞涨卖点

核心条件：

- 位于高位、压力附近、主升后段或派发结构。
- 成交量明显放大。
- 价格涨幅有限、收盘不强，或上影线明显。

含义：成交量放大但价格无法继续上行，说明新增需求被供给抵消。

#### 4.6.4 需求衰竭/加速卖点

核心条件：

- 相对 120 日低点已有较大涨幅。
- 短线涨幅明显加速。
- 多日放量上涨或当日极端放量。
- 振幅明显扩大。

含义：高位连续加速后，需求可能快速透支。加速不是新的低风险买点，已有仓位应优先控制风险。

#### 4.6.5 区间顶部卖点

核心条件：

- 股价接近区间顶部。
- 突破失败、放量滞涨、长上影或缩量无力。

含义：区间顶部需求无法打破平衡，价格倾向回落到区间内部。

#### 4.6.6 下跌中继/回避信号

适用结构：第四阶段主跌。

核心条件：

- 当前处于主跌结构。
- 反弹期间成交量低于均量。
- 反弹不能突破短期均线或压力位。
- 没有强需求反转确认。

含义：主跌趋势中的缩量反弹不能当作底部，应优先回避。

## 5. 评分体系

### 5.1 量价综合分

量价综合分范围为 0 到 100，主要由五部分组成：

| 分项 | 权重/范围 | 说明 |
| --- | --- | --- |
| 结构分 | 最高 30 | 主升最高，筑底和区间次之，主跌大幅扣分 |
| 位置分 | 最高 20 | 越接近有效支撑或压力，信号位置越清晰 |
| 信号分 | -30 到 30 | 买入信号加分，卖出和回避信号扣分 |
| 风险分 | 最高 10 | 止损越明确、距离越合理，得分越高 |
| 相对强度分 | 最高 10 | 个股强于基准指数越明显，得分越高 |

### 5.2 分数解读

| 分数区间 | 解读 |
| --- | --- |
| 80 分以上 | 强信号，需要重点观察，但仍要看最终统一建议 |
| 60-79 分 | 有观察价值，通常需要等待确认 |
| 40-59 分 | 中性或条件不足，不宜急于操作 |
| 40 分以下 | 弱势、风险或优势不足，优先回避 |

量价分不是唯一决策依据。最终动作还会结合 radar 结果、卖出风险和统一决策规则。

## 6. 强股雷达逻辑

### 6.1 Radar 的作用

Radar 是对“这是不是好股票、现在是不是好买点、如果持有是否该卖”的二次诊断。它不会替代量价信号，而是作为过滤器和分层工具。

Radar 输出三个核心分数：

- 强股设置分 setup_score。
- 买点质量分 entry_quality_score。
- 卖出风险分 exit_risk_score。

并输出一个雷达动作：

| 动作 | 含义 |
| --- | --- |
| 可交易 | 强股设置好，买点质量高，卖出风险低 |
| 等待买点 | 股票质量较好，但当前买点不完整 |
| 可关注 | 有一定优势，可进入观察池 |
| 回避 | 市场、结构、强度或风险条件不达标 |

### 6.2 市场状态判断

Radar 会根据基准指数判断市场状态：

| 状态 | 判断逻辑 |
| --- | --- |
| 强市 | 基准指数收盘价高于 60 日均线，且 20 日均线高于 60 日均线 |
| 弱市 | 基准指数收盘价低于 60 日均线，且 20 日均线低于 60 日均线 |
| 震荡市 | 不满足强市或弱市条件 |
| 未知 | 基准数据不足 |

弱市中，即使个股出现买点，系统也会更倾向于“等待买点”或“回避”。

### 6.3 强股设置分 setup_score

强股设置分衡量股票是否具备成为优先候选的基础条件。

加分因素包括：

- 当前处于第二阶段主升。
- 收盘价高于 20 日、60 日、120 日均线。
- 20 日和 60 日均线斜率向上。
- 接近 60 日新高。
- 股票强于基准指数。
- 股票强于所属板块。
- 区间收敛、成交量萎缩、波动率收敛。
- 突破后能站稳。

扣分因素包括：

- 主跌阶段。
- 高位派发阶段。
- 相对强度较弱。

### 6.4 买点质量分 entry_quality_score

买点质量分衡量“现在是否适合买”。

加分因素包括：

- 价格距离有效支撑 1%-4%。
- 回踩深度在 3%-10%之间。
- 最近 3 日成交量明显低于 20 日均量。
- 回踩振幅收敛。
- 支撑未被跌破。
- 止损距离在 3%-7%之间。
- 预估盈亏比达到 1.8 或 2.5 以上。
- 已出现明确买入信号。

扣分因素包括：

- 距离 20 日均线超过 12%，有追高风险。
- 当日跳空高开 5% 以上。
- 止损距离超过 10%。
- 预估盈亏比低于 1.2。

### 6.5 卖出风险分 exit_risk_score

卖出风险分越高，表示越应谨慎。

加分因素包括：

- 处于高位派发或主跌结构。
- 出现卖出信号或回避信号。
- 最近 5 日多次出现长上影。
- 放量滞涨。
- 收盘跌破 20 日均线。
- 20 日相对强度转弱。
- 个股弱于板块。
- 板块强度分位偏低。

### 6.6 Radar 排除原因

常见排除原因如下：

| 原因 | 含义 |
| --- | --- |
| weak_market | 大盘偏弱 |
| weak_or_late_structure | 结构偏弱或处于后期风险结构 |
| weak_relative_strength | 相对强度偏弱 |
| low_setup_score | 强股设置分不足 |
| poor_entry_quality | 买点质量不足 |
| high_exit_risk | 卖出风险偏高 |
| overextended_from_ma20 | 距离 20 日均线过远，有追高风险 |

## 7. 最终统一决策逻辑

系统最终建议不是简单使用量价分，也不是简单使用 radar 动作，而是通过统一决策模块合成。

最终动作包括：

| 动作 | 含义 |
| --- | --- |
| 可买入 | 量价买点成立，买点质量达标，风险没有否定信号 |
| 等待买点 | 股票或信号有价值，但买点质量、市场环境或风险条件不完整 |
| 可关注 | 可放入观察池，但不能直接买入 |
| 减仓/卖出 | 已出现卖出信号或卖出风险较高 |
| 回避 | 结构、信号或环境不支持参与 |

统一决策优先级：

1. 如果出现卖出或回避信号，优先服从量价风险。
2. 如果处于主跌结构，优先回避。
3. 如果卖出风险分达到 70 以上，优先减仓或回避。
4. 如果出现买入信号，但大盘弱势，通常等待确认。
5. 如果买入信号成立，且买点质量分达到 65 以上、卖出风险低于 55，可给出可买入。
6. 如果只有观察信号，则根据结构、强股设置分和风险给出等待或关注。
7. 如果没有清晰量价优势，则回避。

## 8. 价格预测模型

### 8.1 模型定位

价格预测模块用于估计未来 10 个交易日的统计价格路径，包括预测收盘价、预测涨跌幅、上下沿、上涨概率和置信度。

预测模型不是交易信号本身。它用于回答：

- 当前量价买点是否得到统计趋势支持。
- 未来 10 日预期收益是否为正。
- 下沿是否可能跌破止损。
- 当前信号是否属于高风险追入。

### 8.2 默认模型

默认模型参数为：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| horizon | 10 | 预测未来 10 个交易日 |
| lookback_days | 750 | 训练使用最近 750 个有效交易日 |
| min_rows | 250 | 最少需要 250 个有效样本 |
| model | light_var | 优先使用轻量 VAR 模型 |
| interval_z | 1.28155 | 约对应 80% 预测区间的标准正态系数 |
| ridge_alpha | 3.0 | Ridge 回归正则化强度 |

### 8.3 特征变量

预测模型使用以下特征：

- 个股日收益 stock_ret。
- 基准指数日收益 bench_ret。
- 行业或板块日收益 sector_ret。
- 个股相对基准收益 relative_ret。
- 成交量变化 volume_chg。
- 成交量相对 20 日均量 volume_ratio。
- 当日振幅 amplitude。
- 20 日波动率 volatility_20。
- 收盘价相对 20 日均线偏离 ma20_gap。
- 收盘价相对 60 日均线偏离 ma60_gap。
- 20 日均线斜率 ma20_slope。
- 60 日均线斜率 ma60_slope。

Ridge 模型还会使用这些特征的滞后值，滞后周期包括 0、1、2、3、5、10 日，并加入 5 日收益均值、20 日收益均值、20 日收益标准差、5 日成交量变化均值和趋势质量因子。

### 8.4 VAR 模型

当配置为 light_var 时，系统优先使用 VAR 模型。

VAR 使用变量：

- stock_ret。
- bench_ret。
- sector_ret。
- volume_chg。
- volatility_20。
- ma20_slope。

模型最多使用 5 阶滞后，并根据样本长度控制滞后阶数。VAR 的优势是可以同时建模个股、指数、板块、成交量和波动率之间的动态关系，适合轻量、可解释的短周期预测。

### 8.5 Ridge 备用模型

系统始终会先训练 Direct Ridge 作为备用预测。如果 VAR 训练失败，系统自动回退到 Ridge。

Ridge 的优势：

- 对小样本更稳定。
- 正则化可以降低过拟合。
- 可以直接预测 T+1 到 T+10 的累计收益。
- 对异常行情更稳健。
- 不依赖时间序列模型严格假设。

### 8.6 预测区间和上涨概率

系统会根据模型残差标准差和历史未来收益标准差生成预测区间。

预测点包括：

- T+1 到 T+10 的预测收盘价。
- 对应预测涨跌幅。
- 下沿价格。
- 上沿价格。

上涨概率计算方式：

```text
上涨概率 = 标准正态分布函数(预测收益 / 预测标准差)
```

置信度综合考虑：

- 训练样本数量。
- 预测收益与噪声的比例。
- 模型类型。

置信度范围被限制在 20 到 90 之间，避免给出过度确定的结论。

### 8.7 预测结论

预测结论会结合量价动作和止损条件：

| 情况 | 结论倾向 |
| --- | --- |
| 有买点，预期收益 > 3%，上涨概率 >= 60%，且下沿不破止损 | 预测支持当前买点 |
| 有买点，但预测下沿跌破止损 | 有信号但预测风险偏高 |
| 有买点，但预期收益为负或上涨概率低于 50% | 预测不支持追入 |
| 无买点，但预测偏强 | 等待量价买点确认 |
| 卖出或回避信号存在 | 预测不能替代量价风险 |

## 11. 推荐使用流程

### 11.1 盘后复盘流程

1. 扫描股票池，筛选候选分较高且最终动作为“可买入、等待买点、可关注”的股票。
2. 打开单票诊断，查看结构阶段和量价信号。
3. 检查支撑位、压力位、止损价和失效价。
4. 查看 radar 三个分数，确认是否强股、是否好买点、是否有卖出风险。
5. 如使用预测模块，查看未来 10 日预测是否支持当前计划。
6. 将符合条件的股票加入备选池。
7. 次日盘中只观察预设条件是否触发，不临时追涨。

### 11.2 开盘前跟随交易流程

1. 查看海外强势股或手工输入海外涨幅。
2. 生成 A 股产业链映射候选。
3. 叠加 A 股量价诊断。
4. 删除结构弱、买点差、开盘高开过大的标的。
5. 只保留少数观察对象。
6. 开盘后等待量价确认，不把隔夜映射当作直接买入理由。

### 11.3 持仓管理流程

1. 每日更新持仓股票诊断。
2. 重点查看卖出风险分、卖出信号和是否跌破关键价。
3. 若达到 1R，可考虑保本止损。
4. 若达到 2R，可启动移动止盈。
5. 若出现向下反转、向下突破或放量滞涨确认，应优先保护利润。

## 12. 产品优势

### 12.1 可解释

系统不是只输出“买”或“卖”，而是输出结构、位置、信号、证据、止损、失效条件和风险原因，便于用户复盘和修正交易计划。

### 12.2 可复盘

同样的数据会得到同样的诊断结果，减少纯主观判断的波动。回测输出交易流水、资金曲线、候选排名和指标，便于验证策略。

### 12.3 风险优先

系统把卖出信号、主跌结构、止损距离、追高风险、弱市环境放在较高优先级，避免只看上涨机会。

### 12.4 策略分层

突破、主升回踩、区间低吸、底部反转、卖出风险、跟随交易被拆成不同模块，避免把不同胜率和风险特征的信号混在一起。

### 12.5 模型辅助而不喧宾夺主

预测模型只做统计辅助，不覆盖量价和风控规则。这样既能利用机器学习和时间序列模型的优势，又避免把不确定预测包装成确定性交易指令。

## 13. 风险声明与上线合规建议

### 13.1 风险声明

本产品输出的所有分析、评分、预测、回测和候选结果均基于历史行情和预设模型，不代表未来收益。证券市场存在政策、流动性、财务造假、黑天鹅、停牌、涨跌停、滑点扩大、数据错误等风险。

### 13.2 上线前建议

如果产品未来对外上线，建议补充：

- 明确的用户协议和风险揭示书。
- 数据源授权和数据延迟说明。
- 模型版本记录和参数变更记录。
- 回测假设说明，包括手续费、滑点、涨跌停、停牌处理。
- 不构成投资顾问服务的免责声明。
- 用户自定义参数的保存和审计记录。
- 异常数据检测与提示。
- 预测模型的历史误差统计页面。
- 策略在不同市场环境下的分组表现。

## 14. 结语

A股量价信号工作台的目标不是替用户预测确定的未来，而是帮助用户把“看盘经验”转化为一套可解释、可复盘、可验证的流程。它把交易决策拆成结构、位置、信号、风险、强度和预测六个层面，让用户在面对复杂市场时少一点临时起意，多一点计划和纪律。
